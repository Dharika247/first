Folio Slideshow Template

Folio Slideshow is a free, responsive nine-slide presentation template built with pure HTML, CSS, and JavaScript. The soft powder plum and coral palette, paired with Fraunces serif italics, gives photographers, creative studios, and boutique brands a polished foundation for portfolio decks, press kits, and exhibition catalogs.

The structure follows a real portfolio narrative: a magazine-style cover, a drop-cap foreword, a full-bleed featured plate, a typographic index, a centered spread with pull quote, a four-up grid of selected works, press quotes, a cross-promotion grid, and a closing colophon. A unified set of CSS custom properties means swapping the palette or typography updates every slide at once.

A popup table of plates lets viewers jump to any slide. Arrow keys, number shortcuts (1 to 9), and swipe gestures all work for navigation. Slides become scrollable on smaller screens, and the chrome unsticks into an in-flow footer to free up space. Drop the file into any folder and it just works.

Features

+ Single-file vanilla HTML, CSS, and JavaScript with no frameworks
+ Nine fully designed slides with serif italic typography throughout
+ Drop-cap foreword and full-bleed featured plate with overlay caption
+ Four-up selected works grid with portrait-ratio image cards
+ Popup table of plates with keyboard shortcut hints
+ Editorial page-turn slide transitions with mask-wipe reveals
+ Cross-promotion card grid linking to other TemplateMo templates
+ Mobile-scrollable slides with custom coral-tinted scrollbars
+ In-flow footer on mobile that replaces sticky chrome
+ Keyboard navigation, touch swipe gestures, and `data-goto` link system
+ Fully responsive across desktop, tablet, mobile, and landscape viewports
+ Three Google Fonts loaded: Fraunces, Inter Tight, JetBrains Mono
+ Free for personal and commercial use under the TemplateMo license
